FAQ

Aam Sawaal (Questions & Answers)

Kya is app ke liye API key, Firebase ya login chahiye?

Nahi! Baby Assistant 100% free aur standalone hai. Isme Android ka built-in SpeechRecognizer, TextToSpeech, aur TelecomManager use hota hai — koi account ya API key setup nahi karna padhta.

Incoming call aate hi mic automatically kaise ON hota hai?

Jab aap app ke andar Voice Assistant toggle ON rakhte hain, to app ki Microphone Foreground Service armed rehti hai. Call ring hote hi bina button dabaye mic listen start kar deta hai. Android 14+ par best performance ke liye Settings mein Battery Optimization ko Unrestricted set karein.

Install karte waqt Google Play Protect warning aaye to kya karein?

Kyunki yeh APK direct website / GitHub se download kiya jata hai (Play Store ke bahar), Android pehli baar confirm karta hai. Aap More details → Install anyway select karke safely install kar sakte hain.

Kya meri call audio ya awaaz record ya upload hoti hai?

Bilkul nahi. Baby Assistant koi audio file record ya cloud par upload nahi karta. Sirf recognized command ka text log aapke phone ke local storage mein dikhta hai, jise aap kabhi bhi delete kar sakte hain.
